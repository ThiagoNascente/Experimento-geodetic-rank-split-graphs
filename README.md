# MAC e Linux

Gere um ambiente virtual python

```bash
python3 -m venv venv
```

Ative o ambiente virtual

```bash
source .venv/bin/activate
```

Instale as libs, estando dentro da venv

```bash
pip install -r requirements.txt
```

# Windows

Gere um ambiente virtual python

```bash
py -m venv venv
```

Ative o ambiente virtual

```bash
.\venv\Scripts\activate
```

Instale as libs, estando dentro da venv

```bash
pip install -r requirements.txt
```
